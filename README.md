## 🚀 Deployment

### 💻 Option 1 — Local Machine or GitHub Codespaces

> Works on Windows, Mac, Linux and GitHub Codespaces.

**Step 1 — Clone the repo:**
```bash
git clone https://github.com/jeremi563/cypheron-whatsapp-bot.git
cd cypheron-whatsapp-bot
```

**Step 2 — Run the setup wizard:**
```bash
npm run setup
```

> The setup wizard will automatically install dependencies, create your `.env` file, prompt for your Session ID and launch the bot. Just follow the prompts.

**Step 3 — Start the bot anytime:**
```bash
npm start
```

---

### 🌐 Option 2 — Deploy on Render (24/7 Free Hosting)

> Render keeps your bot online 24/7 for free.

**Step 1** — Fork this repo on GitHub

**Step 2** — Go to [render.com](https://render.com) and sign in with GitHub

**Step 3** — Click **New** → **Web Service** → Connect your forked repo

**Step 4** — Fill in these settings:

| Setting | Value |
|---|---|
| **Build Command** | `npm install` |
| **Start Command** | `node index.js` |
| **Instance Type** | Free |

**Step 5** — Add these environment variables:

| Key | Value |
|---|---|
| `SESSION_ID` | Your session ID from cypheron-session.onrender.com |
| `GNEWS_API_KEY` | Free key from gnews.io |
| `OMDB_API_KEY` | Free key from omdbapi.com |
| `NODE_VERSION` | `20` |
| `TZ` | `Africa/Nairobi` |

**Step 6** — Click **Create Web Service** and wait for deployment

**Step 7** — Set up [UptimeRobot](https://uptimerobot.com) to ping your bot URL every **14 minutes** to prevent sleeping
